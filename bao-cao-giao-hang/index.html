Chuẩn bị dữ liệu Người làm

Kiểm tra file Excel tháng trước khi đưa lên.

  • Sheet dữ liệu check đơn hàng thô (có cột Mã các đơn hàng và Thời gian trả Check)
  • Sheet MNV: mã và họ tên nhân viên giao hàng
  • Sheet Thông số chính sách: đúng Tháng / Năm áp dụng, ngày sáng đẩy hàng, ngày đi công tác
  • Sheet Chấm công của tháng (mã X, S, C, P, P.s, P.c, Ro…)
  • Tháng mới: đặt tên file mới, ví dụ GIAO HÀNG THÁNG 10.xlsx
2

Cập nhật dữ liệu Người làm

Kéo thả file Excel vào khung dưới đây — file được đưa thẳng vào hệ thống, rồi tự tính lại và gửi mail theo lịch.

🔑 Kết nối hệ thống

Làm 1 lần trên mỗi máy. Dán token truy cập (bắt đầu bằng github_pat_) rồi bấm Kết nối. Token chỉ lưu trong trình duyệt của máy này.

Chưa có token? Cách tạo (2 phút)
  1. Đăng nhập GitHub (tài khoản quản trị), mở trang tạo token ↗
  2. Token name: Kho van HCM web · Expiration: chọn thời hạn (ví dụ 1 năm)
  3. Repository access: Only select repositories → chọn BAO-CAO-GIAO-HANG
  4. Permissions → Repository permissions: Contents = Read and write, Actions = Read-only
  5. Bấm Generate token, copy token và dán vào ô ở trên

3b Tính toán

Áp đúng quy tắc trong "Thông số chính sách" và mã chấm công thực tế.

  1. ✓Đọc workbook
  2. ✓Tìm sheet dữ liệu & chấm công
  3. ✓Đọc chính sách (định mức, hệ số K, hệ số lương…)
  4. ✓Đọc mã chấm công (công / phép / nghỉ khác)
  5. ✓Gộp đơn giao theo nhân viên + ngày
  6. ✓Tính điểm, định mức, hệ số lương từng ngày
  7. ✓Tổng hợp theo nhân viên

Lưu trữ & tra cứu

Mọi phiên bản file đều được giữ lại, xem hoặc khôi phục bất cứ lúc nào.

  • Tải file đã tính: mở file trong data → nút Download
  • Xem phiên bản cũ: mở file → History
  • File tháng cũ có thể để lại làm lưu trữ — hệ thống luôn dùng file được tải lên gần nhất

Quy tắc tính đang áp dụng

Đổi quy tắc cần sửa cả script tự động lẫn công cụ trên trang này để kết quả khớp nhau.

  • Sáng đẩy hàng (dù rơi ngày thường hay Thứ 7) luôn tính đạt 100%, không đánh giá theo định mức.
  • Nghỉ phép nửa ngày (mã chứa P.s / P.c) cũng tính 100% lương, gộp vào cột "Phép" riêng.
  • "Số ngày công" = công thực tế (mã X=1, S/C=0.5…) cộng luôn phép — khớp đúng "Tổng" trong bảng Chấm công.
  • Mã Ro (đổi ca / nghỉ lý do khác) tách hẳn ra cột riêng, không cộng vào công lẫn phép.
  • Các sheet khác trong file (Check tháng X, MNV, Thông số chính sách, Chấm công…) được giữ nguyên, chỉ 3 sheet Đơn giao / Theo ngày / Tổng hợp NV được tính lại.
