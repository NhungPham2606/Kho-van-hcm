      Thả file kho và file sàn của tháng vào đây (1 hoặc 2 file cùng lúc)

      File kho: giống file Thưởng kho HCM (sheet Bảng check kiện hàng + bảng mã nv, có thể kèm THƯỞNG). File sàn: giống file Thưởng sàn HCM (sheet có cột Bốc hàng, TG Bốc hàng, Đóng hàng, TG Đóng hàng; 1 hay nhiều sheet đều được). Trang tự nhận file nào là kho, file nào là sàn và tự nhận tháng. File sàn không có bảng mã nv thì dùng bảng mã của file kho. Nạp lại cùng tháng = thay file cũ của tháng đó (lỗi chất lượng / ghi chú đã nhập vẫn giữ).

      ThángFile khoFile sànChấm côngĐóng cặp (Thưởng kho / sàn)
      Tổng điểm 100 = Năng suất () + Ổn định () + Chất lượng (). Xếp loại: A ≥ · B ≥ · C ≥ · D dưới . Dưới ngày công: không xếp loại (—).
      • Lượt đếm giống trang thưởng: kho = Tạo kiện + Bốc hàng + Đóng hàng (mỗi dòng 1 lượt); sàn = Bốc hàng + Đóng hàng. Lượt quy đổi = lượt kho + lượt sàn × (đơn sàn nhỏ, nhanh hơn: định mức thưởng kho 20 lượt/ngày, sàn 80).
      • Ngày công lấy từ bảng chấm công cùng tháng (trang Chấm Công: X = 1, S / C và các mã nửa ngày = 0,5; P, L, Ro, CT… = 0). Chưa có chấm công thì lấy những ngày có lượt quét (thứ Bảy = 0,5). Có quét vào ngày nghỉ / CN thì ngày đó cũng tính công.
      • Năng suất = bình quân lượt quy đổi / ngày công so với trung bình nhóm; đạt % trung bình nhóm trở lên = đủ điểm, thấp hơn tính theo tỷ lệ (bằng trung bình nhóm ≈ điểm).
      • Ổn định = tỷ lệ ngày có công đạt định mức lượt quy đổi (nửa ngày: một nửa) × .
      • Chất lượng = − số lỗi ghi nhận × (không âm) — nhập ở mục Chất lượng & ghi chú.
      • Đóng cặp khai ở trang Thưởng kho / Thưởng sàn được chia đôi y như khi tính thưởng — không thì 1 người được ghi hết lượt của cả 2.
